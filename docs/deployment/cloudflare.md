# Cloudflare Configuration Guide

## Overview
This document covers the domain name routing, DNS management, and edge security setup via Cloudflare.

## DNS Setup
- **A Record**: Points target domain/subdomain to the Azure VM public IP address.
- **Proxy Status**: Cloudflare proxy status mode.

## Security & SSL/TLS
- SSL/TLS encryption setting between client, Cloudflare edge, and Azure VM host.
